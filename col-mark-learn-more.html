3D Column Grid Marks

Every column face shows its grid line, right in the model.

3D Column Grid Marks (COL MARK) places grid-line marks on every structural column in Revit, turned and sized to the column, and keeps them up to date as columns and grids change. Steel connections never hide them.

Built for Steel Column Coordination

Detailers, modelers and erectors need to know at a glance which grid line each column face points to. 3D Column Grid Marks puts that answer on the column itself, in 3D views, sections and exports, without editing your column families.

Supports Revit 2024, 2025, 2026 & 2027

The COL MARK Tab

Grid Marks

Places or updates a marker on every column in the project, the active view, the selection, or columns you pick.

Auto Update

Markers follow columns as they are placed, moved, rotated, resized or connected, and update when grids change.

Remove Markers

Clears the markers of the selected columns or the whole project. The columns themselves are never changed.

How the Marks Read

Each face shows the grid line you look along when you face it.

  • WEB — the nearest grid line that runs across the web.
  • FLG — the nearest grid line that runs along the web.
  • Direction comes from the column's own geometry, so rotated and mirrored columns are marked correctly.
  • Optionally add the offset when a column is off its grid, e.g. B (1'-6").

Features

  • Works with W shapes, rectangular and square HSS, and round pipe
  • No special parameters needed in your column families
  • Markers are separate elements, so steel connections never hide them
  • Markers are pinned so they aren't moved by accident
  • Marks at low, middle and high heights, with overrides
  • Steel-only filter, swap WEB/FLG, skip off-grid columns
  • Clear report of placed, updated, unchanged and skipped columns
  • Each run is a single Undo step

Getting Started

  1. Open a project with structural columns and straight grid lines.
  2. Click COL MARK > Grid Marks.
  3. Choose the columns, set the options and click Update. The marker family loads automatically the first time.
  4. Turn on Auto Update to keep markers in step while you model.

Press F1 on any COL MARK button for help.
