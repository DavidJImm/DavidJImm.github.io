BIM Pro for Autodesk Revit

Work smarter. Start where you left off.

Practical tools that make everyday Revit work faster.

BIM Pro is a Revit productivity toolkit built around the tasks users perform repeatedly: restoring their workspace, remembering worksets, exporting drawings, managing pile coordinates, moving schedules between Revit and Excel, and cleaning up unwanted linetypes.

What BIM Pro Does

BIM Pro adds a dedicated set of productivity tools directly to Revit. The emphasis is simple: reduce repetitive clicks and setup work while keeping commonly needed commands close at hand. Several BIM Pro features operate automatically in the background, so users can simply work normally while BIM Pro remembers the information needed for the next session.

Revit Workspace & Session Management

↻

Automatic Session Memory

BIM Pro automatically keeps track of the Revit views you have open while you work and saves the most recent session for the active model when the model closes.

  • Remembers open non-template Revit views.
  • Stores the view information needed to restore the session.
  • Automatically attempts to restore the saved views when the model is opened again.
  • Helps you return to the same plans, sections, elevations, schedules, and 3D views.
✓

Save Session

Save Session remains available as a manual command when you want to immediately save the current open-view session.

  • Useful when you want an immediate snapshot of your current workspace.
  • Replaces the previously saved session for the active model.
  • Normal use does not require manually saving before closing Revit because BIM Pro saves automatically.
□

Restore Session

Restore Session restores the views contained in the saved session for the active model.

  • Restores views that still exist in the project and can be opened by Revit.
  • Reports views that can no longer be opened.
  • Can close currently open tabs that are not part of the saved session when possible.
W

Workset Memory

BIM Pro automatically remembers the active user workset for each workshared Revit model and restores it when the model is opened again.

  • No manual save or restore command is required.
  • When you change the active workset, BIM Pro updates the remembered workset.
  • Works with workshared models.
  • Does not change the active workset in non-workshared models.
The result: open your Revit project and get back to the workspace you were using instead of rebuilding it every time.

Drawing Production & Coordination

PDF

PDF / DWG Export

Export selected Revit sheets to PDF, DWG, or both using the export settings available in the current project.

  • Select one or more sheets.
  • Choose PDF, DWG, or PDF + DWG.
  • Select the available PDF and/or DWG export setup.
  • Choose an output folder.
  • Optionally add a revision suffix.
  • BIM Pro remembers the export folder, prefix, revision preference, and selected export setups for the project.
PC

Pile Coordinates

Pile Coordinates helps streamline pile identification, numbering, and coordinate/elevation information within a Revit project.

  • Identifies pile members using BIM Pro's pile criteria, including PILE or PILING in Structure Name or MTO Bldg ID.
  • Optionally numbers piles.
  • Set a numbering prefix, starting number, and number of digits.
  • Choose North/South and West/East sorting order.
  • Writes Easting, Northing, Top of Pile, and Bott of Pile information to pile parameters.
  • Uses Piece Mark for pile numbering.
⌁

Purge Linetypes

Quickly clean unwanted imported line patterns from the current Revit document.

  • Uses BIM Pro's built-in filtering rules.
  • Removes line patterns whose names contain IMPORT.
  • Provides a focused cleanup command without requiring a larger project cleanup workflow.

Excel Tools

XL

Schedule → Excel

Export one or more Revit schedules to Excel workbooks for sharing, reporting, analysis, or further editing.

  • Select the schedules to export.
  • Choose a destination folder.
  • BIM Pro creates an Excel workbook for each selected schedule.
  • Schedule headers, body data, and footer data are read from the Revit schedule.
  • File names are cleaned of characters that Windows does not allow.
→R

Excel → Revit

Bring an Excel worksheet into a Revit drafting view as a formatted table.

  • Choose the Excel workbook.
  • Select the worksheet.
  • Enter or confirm the Revit view name.
  • Choose whether the first row is a header.
  • Select an existing Revit Text Style.
  • Import the table into the drafting view.

The selected Revit Text Style controls the imported text appearance. BIM Pro does not create a new text style for this operation.
